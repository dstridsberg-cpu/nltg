Koppla appen till GitHub (görs en gång)

Appen behöver en nyckel för att få lägga upp prototyper i ditt repo . Nyckeln sparas bara i den här webbläsaren.

  1. Öppna sidan för nya nycklar på GitHub (öppnas i en ny flik).
  2. Skriv ett namn, t.ex. Prototyper, och välj hur länge den ska gälla (t.ex. ett år).
  3. Under Repository access: välj Only select repositories och välj .
  4. Under Permissions → Repository permissions: sätt Contents till Read and write och Pages till Read and write.
  5. Klicka på Generate token, kopiera nyckeln (börjar med github_pat_) och klistra in den här:
